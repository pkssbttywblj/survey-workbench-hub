# `survey-workbench` 技能

[English](README_EN.md)

输入一个关键词，产出可查询的资料库与按基金规范写成的调研报告；报告还能极度精简成科研汇报 PPT。

## 适合用它做什么

- 开题或基金本子前，把某方向的论文、预印本、报告、网页资料摸一遍
- 需要一套能反复查的文献库（Excel 索引 + SQLite），而不是一次性文件夹
- 要按研究阶段由早到晚写「国内外研究现状 + 发展动态分析」
- 报告写完后要一份逻辑完全一致的汇报 PPT
- 需要把中文库与机构库也纳入检索范围：28 个渠道一键链接 + 机构授权引导（可选）

## 典型请求

```text
帮我按阶段梳理「复合材料固化工艺优化」的国内外研究现状，
公开资料能下的都下，闭源的给 DOI 和获取通道，最后出报告和 PPT。
```

## 你需要提供

- 研究方向关键词（中英文都可以）
- 可选：篇数、时间范围、是否要 PPT、是否指定机构权限

## 产出

| 产物 | 位置 |
|---|---|
| 规范化资料库 | `01_文献/`、`02_开放资料/` |
| 索引 | `00_索引/索引表.xlsx`、`library.db` |
| 未获取清单 | `05_报告/未获取资料清单.md`（DOI + 一键检索） |
| 获取指引 | `05_报告/文献获取指引.md`（28 渠道 + 授权询问） |
| 报告 | `05_报告/研究现状_<主题>.md` / `.docx` |
| PPT | `05_报告/研究现状_<主题>.pptx` |

## 边界

- 机构登录、验证码由用户手动完成；skill 不接触账号密码
- CNKI/万方/维普有验证码或 JS 渲染，脚本不自动抓；给一键检索链接，授权询问只问一次
- 扫描件走多模态读图；OCR 只在用户明确要求高精度表格时启用
- PPT 引擎已内置（CN Academic Spark，含模板/图标/技术路线图库，约 102 MB），不依赖本机另装 skill；用户要 PPT 时才调用，内容只取已有调研成果

## 工作方式

P0 环境自检 → P1 需求确认 → P2 多源检索 → P3 筛选分级 → P4 获取 → P5 归档解析 → P6 建索引 → P7 交互 → P8 报告 → P9 PPT。

详细规则与脚本参数见 [SKILL.md](SKILL.md)。

## 运行和依赖

Python 3.9+；`openpyxl`、`pymupdf`、`pdfplumber`、`python-docx`、`beautifulsoup4`。
可选 `curl_cffi`（下载成功率）、tesseract / OCR-VLM（高精度表格）。
